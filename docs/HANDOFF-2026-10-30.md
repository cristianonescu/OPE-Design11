## How the day was run (keep this)

  integration PR per round: #188 (8 PRs), #201 (17 PRs), #214 (11 PRs) and the final integration PR (the last ones,
  with these release docs).
- Lessons:
  - Never base a PR on an integration branch: deleting it after the merge auto-closes the PR (#202).
  - Union-merged docs must be read, not just counted: the union driver had written ROADMAP items 6
    and 8 five and three times over on main. `verify-docs.py` (coordinator's scratch tool) now
    checks rows, stale lines and duplicate ROADMAP items; also read every paragraph two sources
    touched.
  - Stacked PRs carry their parent's commits; after a squash merge, rebase so only their own
    commit remains (or cherry-pick it onto main).
  - Platform maths: `openstitch_design::fmath::Det` (over `libm`) is the only allowed source of
    transcendental functions in the design crate; a source-scan test enforces it.
