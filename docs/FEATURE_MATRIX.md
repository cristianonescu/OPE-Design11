# Feature matrix

Status values: Not Investigated · Documented · Implemented · Partially Compatible ·
Verified Compatible · Blocked.

"Documented" rows come from Brother's public online user's guide; headings and links are in
[research/pedesign11-manual-toc.md](research/pedesign11-manual-toc.md). "Verified Compatible" requires a reproducible test against PE-DESIGN 11 reference
output, which needs a licensed installation (see ROADMAP.md). **No row is Verified
Compatible yet.** "Oracle-tested" means checked against pyembroidery, an independent
implementation: evidence that the code works, not proof of PE-DESIGN equivalence.

The compatibility tier each row has reached in the harness (internal regression, oracle,
PE-DESIGN reference, sew-out) is generated from the compatibility report into
[COMPATIBILITY_STATUS.md](COMPATIBILITY_STATUS.md). Do not edit that table by hand.
