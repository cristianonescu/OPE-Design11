## How the day was run (keep this)

- Seven parallel track sessions (references, PES 0110 writer, colour and limits, stitch engine,
  sew order and fills, image digitizing, pattern formats), each ending in PRs.
- **Queued PRs are batched (owner's rule):** the coordinator merges every waiting PR into one
  `integration/<date>-<n>` branch from main, resolves conflicts, runs fmt, clippy, the compat
  harness (status table regenerated), the gate test and the crate tests locally, and opens one PR
  (one CI run). Originals are closed as "included". Today: #155 (ten PRs), #166 (seven PRs plus
  commits), Integration 3 (the rest, with this handoff and the alpha.6 notes).
- Lessons: build the merged tree before pushing (a new struct field only fails at compile time);
  merge doubled FEATURE_MATRIX rows against the rows' common ancestor, not the new main; keep
  rows main deliberately lists twice; `.gitattributes` keeps the PSC sources (`.pas`, `.pmf`,
  `.plf`) byte-exact so their SHA-256 matches on every OS; GitHub runs no CI on a conflicting PR;
  cancel individual CI on PRs queued for the next batch while an integration PR is in CI.
- PE-DESIGN stays black-box: its UI and the files it saves. Brother's bundled fonts, motifs and
  patterns are never read. Every icon or graphic is generated with Higgsfield. Every behaviour PR
  updates FEATURE_MATRIX, COMPATIBILITY_AUDIT and ROADMAP.
