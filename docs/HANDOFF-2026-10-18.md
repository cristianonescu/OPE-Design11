The project's state at the end of the first day: what exists, what is left toward the goal, and

## Update 2026-10-19

Bézier outlines and point editing landed in the engine (`shape.path`, `object.setPoint`,
`object.insertPoint`, `object.deletePoint`, `object.setSegment`). It has 150 tests,
`examples/heart.json` and `docs/images/engine-heart.png`. Next: the editor UI for point editing
and a Bézier pen tool, then lettering.

## Update 2026-10-19 (drawing and editing)

Item 1 ("Drawing and editing") is done in the engine and the editor: `shape.arc`,
`shape.preset`, rounded rectangles, `object.group`/`ungroup`, `object.arrangeCopies`,
`shape.merge`/`removeOverlap`/`combine`/`split`/`offsetLines` (on `i_overlay`; openstitch-design

Example: `examples/drawing.json`, `docs/images/rust-editor-drawing.png`.

## Update 2026-10-19 (digitizing)

Image to embroidery landed: crate `openstitch-digitize` and engine commands `digitize.autoPunch`,
`digitize.crossStitch`, `digitize.photoStitch`, `digitize.lineImage`, `digitize.figure`,
`digitize.designCenter`, plus the editor's Design → Image to Embroidery… dialog. All are this
project's own algorithms, documented as approximations (ARCHITECTURE.md → Digitizing). Next:
image preview in the dialog, masks/cropping, per-colour sew choices, an interactive figure
stage, and calibration against PE-DESIGN once a reference install exists.

## Update 2026-10-19 (files)

Item 4 ("Files"), see FILE_FORMATS.md for layouts and evidence:
- **HUS and VIP** read and write, with OpenStitch's own LZ77 + Huffman (`-lh5-` style)
  compressor (`openstitch_formats::lzh`). pyembroidery decodes OpenStitch's HUS identically;
  VIP's colour table was confirmed with libembroidery.
- **SHV, PHC, CSD** read only (`FileType::can_write`; `design.export` refuses them). CSD is
  spec-derived (libembroidery's public de-obfuscation).
- **PES**: v4+ metadata, v5+ RGB thread table, `CEmbOne`/`CSewSeg` objects (`pes::read_objects`).
  v1/v6 writers are byte-identical to pyembroidery (`design.export` `pesVersion`; default stays
  `1t`).
- **Imports**: `import.svg` (usvg; grouped Bézier shapes), `background.set/show/clear`
  (reference image saved in `.osd` and drawn by the editor; File ▸ Import SVG…, Background
  Image).
- **Blocked:** PHX (no public description), PEN (encrypted purchase format), editable PES
  shapes/text (no public description), CSD/SHV export (no writer, unknown header bytes), FCM
  (owner decision, see FILE_FORMATS.md), WMF/EMF (no vetted parser).

## Update 2026-10-19 (Design Database)

The Design Database landed: crate `openstitch-library` (folder listing and bounded walks,
Property information, thumbnails, search, new folder / copy / move / rename / delete to the OS
trash without ever overwriting, batch conversion, catalogues as PDF, PNG pages, HTML and CSV)
and the editor's File ▸ Design Database… mode (`database_ui.rs`, model `editor::database`).
Every file and folder is treated as hostile (size, depth and count limits; folder links never
followed; FIFOs never opened). Screenshots: `docs/images/database-*.png`,
`docs/images/library-catalogue.png`. Next: Send to USB media through the USB-stick transfer
command when it lands; `library.*` engine commands for MCP.

## Goal

An independent, clean-room embroidery suite that reproduces the functionality of Brother
PE-DESIGN 11, written in Rust and running on macOS, Windows and Linux, with compatibility proven by
reproducible tests.

## What is left

Priority order. Items 1 and 2 unblock most of the others.

1. **Drawing and editing.** Bézier outlines and point editing (move/insert/delete points,
   straight↔curve); arcs and preset shapes; group/ungroup; arrange copies; boolean shape
   operations (split, combine, offset lines); copy sewing attributes; entry/exit points.
2. **Lettering.** Text objects, text on a path, monograms, templates, Name Drop (text lists),
   TrueType conversion. Use independently licensed fonts only.
3. **Remaining stitch types.**
   - Line: motif, stem, candlewicking, E/V, chain, cutting lines.
   - Region: programmable fill, motif fill, piping, cross stitch, concentric circle, radial,
     spiral, flexible spiral, stippling, net fill, zigzag net fill, decorative fill.
   - Satin: auto direction, underlay variants, gradation, half stitch, feathered edge,
     long-stitch splitting.
   - Fill: travel inside the region instead of jumps.
4. **Files.**
   - Editable PES object section, so designs round-trip with PE-DESIGN.
   - Export HUS and VIP (compression), SHV, CSD (no public spec).
   - Import PHC, PHX, PEN (contents unknown; PEN may be protected, in which case it is out of
     scope).
   - SVG/WMF/EMF and image import; ScanNCut FCM.
5. **Image to embroidery.** Auto Punch, Photo Stitch 1 and 2, Cross Stitch from an image, and the
   Design Center pipeline. Black-box specification only; decompiling Brother code is blocked.
6. **Wizards.** Appliqué, embroidered patch, cutwork, background fill, split designs,
   multi-position hoops, jumbo frame, Print and Stitch.
7. **Machine and workspace.**
   - Hoop and machine-type selection, rulers, measure tool, realistic preview, thread length and
     sewing time.
   - Wireless transfer and Link (protocols undocumented, lowest priority). USB-stick transfer
     works today.
8. **The other suite programs.** Design Database, Programmable Stitch Creator, Font Creator,
   Stitch Design Factory.
9. **Distribution.** Signed builds per OS (app bundle, MSI/MSIX, AppImage/Flatpak);
   file-manager thumbnails for PES/PEN.
10. **Automation hardening.** Per-command capabilities for MCP/control clients; a loopback
    socket transport for the live app (token auth, file roots).

## Ground rules for whoever continues

- Never use or analyse licence-circumvention material, and never bypass licensing.
- No Brother code, fonts, designs or UI assets in the product. Specify behaviour from the public
  guide ([research/pedesign11-manual-toc.md](research/pedesign11-manual-toc.md)), public format
  descriptions, the pyembroidery oracle, and, once available, black-box observation.
- Rust only. Every edit goes through the command registry: add a command, give it
  `ParamDoc`s, and extend `bad_parameters_fail_cleanly`.
- Workspace `members` are listed explicitly in `Cargo.toml`; add a crate only once it builds.
- Golden regressions (`badge-golden.pes`, `badge-golden.osd`) must keep passing. If a deliberate
  change alters output, re-record them in the same commit and say why.
- Commit and push to `main` directly (the owner's preference). Several sessions may share the
  checkout, so commit only your own files.

## Environment notes

- Rust 1.99.1 via Homebrew `rustup`. It is not on the shell `PATH`:
  `export PATH="/opt/homebrew/opt/rustup/bin:$PATH"`.
- `x86_64-pc-windows-gnu` std is installed, so `cargo clippy --target x86_64-pc-windows-gnu`
  catches Windows-only warnings before CI does.

- Test data generators need pyembroidery in a venv: `tools/genfixtures.py` (oracle fixtures),
  `tools/gen_tables.py` (thread charts, PEC icon). Run with `python -I`.
- A local tag `pre-squash-backup` holds the old 17-commit history in this checkout only. Delete it
  with `git tag -d pre-squash-backup` once it is no longer wanted.
