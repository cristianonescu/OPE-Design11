# OpenStitch 0.1.0 alpha 3

The third alpha of OpenStitch, an independent, cross-platform embroidery design application for
macOS, Windows and Linux, built to work with Brother machines and with designs made in
PE-DESIGN 11. OpenStitch is not affiliated with Brother Industries.

Where alpha 2 checked the first 16 test designs against PE-DESIGN 11.50, alpha 3 checks 102
of them, and for the simple shapes OpenStitch now sews the same needle points as PE-DESIGN, in the
same order. **It is still an alpha for testing, not for production work.** Read "Before you sew"
below.

## What changed since alpha 2

### Stitching calibrated against PE-DESIGN 11.50

Every item below was measured on files PE-DESIGN saved and is pinned by a test that compares
OpenStitch's output with that file ([docs/COMPATIBILITY_STATUS.md](../COMPATIBILITY_STATUS.md)).

- **Fill:** PE-DESIGN's row structure: the needle grid is anchored at the first row, rows are
  bricked by the Frequency setting (default now 30 %, as in PE-DESIGN), each row's last stitch runs
  straight into the next row, the last row lands on the far edge, and the first row goes out and
  back. Density and pull compensation take PE-DESIGN's full ranges (0.1–14 lines/mm) and were
  checked across them. Rectangles at 0° and 90° now sew PE-DESIGN's needle points exactly.
- **Gradation** is PE-DESIGN's pattern: density falls from a maximum to a minimum across the
  shape (default 53 % to 5 %), and gradation and feathered edge follow the guide's rules on which
  options can be combined. The feather width is 3.0 mm.
- **Satin:** PE-DESIGN's section order, tie-in and lock steps, feathered edge, and the corner
  fan on Auto satin (the rows turn with the band around a corner). Satin crossings stay whole.
- **Lines:** running, triple, zigzag, E, V, stem, candlewick and chain stitches take PE-DESIGN's
  defaults, tie-ins and locks; stem, candlewick and chain land on PE-DESIGN's needle points.
  Start/End type (Feed or Run) keeps the pattern in place when the start point moves, as
  PE-DESIGN does.
- **Shapes** drawn with the shape tools start and end their sewing where PE-DESIGN's do.
- **Text:** size and line spacing are measured as in PE-DESIGN (size 0.7 em; line spacing in % of
  the character height); new text sews as Satin at density 5.0 with no under sewing, PE-DESIGN's
  text default; Fit Text to Outline has PE-DESIGN's options; Text Transform offers 24 of its 26
  envelope presets, fitted to PE-DESIGN's output; inside a text, every letter's region is sewn
  first, then every outline.

### Files

- **PE-DESIGN 11 files:** OpenStitch reads the editable shapes in PES files saved by PE-DESIGN 11
  (`#PES0110`): geometry, sew type, density, direction, colours, under sewing and line
  attributes. Text records are read as letters with their font name (the way PE-DESIGN stores
  them). Turning these into editable OpenStitch objects on open is the next step; in alpha 3 they
  are available through the format library and `stitchtool`.
- **Machine stream:** every jump inside a design is trimmed, as PE-DESIGN does; repeated needle
  points are dropped; the PEC label is the file name. A PES file without a stitch section (which
  PE-DESIGN writes for an off-page design) is reported as unsupported instead of opening empty.
- Trims between same-colour parts are stored as PE-DESIGN stores them; PE-DESIGN's own thread
  names are read correctly.

## Before you sew

- **Do a test sew-out on scrap fabric** before using a design on anything that matters. No
  OpenStitch file has been sewn on a Brother machine as part of testing yet; the first four
  sew-out files are prepared and waiting for the owner's machine.
- **Known differences from PE-DESIGN 11:**
  - **Text:** a satin text sews fewer stitches than PE-DESIGN's (221 vs 285 on a 20 mm H); text
    fills sew about 14 % more after the fill row change. Text Transform fan presets 13 and 14 are
    not available.
  - **Programmable fill** sews about half of PE-DESIGN's stitch count (2221 vs 4076 on the 40 mm
    test square); the pattern geometry is not yet calibrated.
  - **Feathered edge:** PE-DESIGN has separate top and bottom row switches and feather patterns;
    OpenStitch has one width and start/end/both.
  - **Multi-part regions** (the U shape, letters with holes) sew their parts in OpenStitch's order,
    not PE-DESIGN's.
  - **Motif lines** are uncalibrated: PE-DESIGN's default motif is its own artwork, so there is no
    reference to compare with.
  - **Machine formats other than PES** (DST, EXP, JEF, PCS, SEW, XXX, HUS, VIP): PE-DESIGN's
    exports exist as references but have not been compared yet.
  - **Editable objects:** OpenStitch does not yet write PE-DESIGN 11's editable objects, so a PES
    from OpenStitch opens in PE-DESIGN as a stitch pattern.
- **Keep your original PE-DESIGN files.** Save OpenStitch's output under a new name.
- **Blocked features:** these protocols are undocumented and will not be reverse-engineered:
  wireless transfer and Link; USB Link and network machine settings; Card Reading.
- **macOS:** double-clicking a file in Finder does not open it in OpenStitch yet, and files
  can't be dragged onto the window. Use File ▸ Open, or pass the file on the command line.

The remaining known differences from PE-DESIGN 11, and which are fixed, are listed in
[docs/COMPATIBILITY_AUDIT.md](../COMPATIBILITY_AUDIT.md).

Please open an issue for anything that sews differently from what you expect, crashes, or works
differently from PE-DESIGN 11. Attach the `.osd` or exported file and say which machine you
used.
