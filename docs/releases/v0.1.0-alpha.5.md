# OpenStitch 0.1.0 alpha 5

The fifth alpha of OpenStitch, an independent, cross-platform embroidery design application for
macOS, Windows and Linux, built to work with Brother machines and with designs made in
PE-DESIGN 11. OpenStitch is not affiliated with Brother Industries.

Alpha 5 is the first release that arrives through the editor's own updater (alpha 4 offers it at
startup), and the first with the third round of PE-DESIGN 11.50 calibration: gradation rows,
satin bends, satin gradation and minimum density, under sewing type 2, the two missing Text
Transform presets, machine-format exports as PE-DESIGN writes them, and PE-DESIGN's trim rule.
Two editor fixes the owner asked for are in as well: the installed app icon and a "Save changes?"
prompt. **It is still an alpha for testing, not for production work.** Read "Before you sew"
below.

## The builds are not code-signed

- **macOS:** the first time, right-click `OpenStitch.app` and choose **Open**, then **Open**
  again. Alternatively, run `xattr -dr com.apple.quarantine /Applications/OpenStitch.app`.
- **Windows:** in the SmartScreen prompt, choose **More info → Run anyway**.

## What changed since alpha 4

### Editor

- **The editor asks before discarding work.** Closing the window, Quit (also Cmd+Q and Cmd+W on macOS),
  File ▸ Exit, File ▸ New and File ▸ Open with unsaved changes now show "Save changes to NAME?" with **Save**, **Don't
  Save** and **Cancel** (Enter saves, Esc cancels). The title shows **•** while the design is
  unsaved. Alpha 4 closed silently and lost the design. On macOS the default application menu is no
  longer installed (its Quit bypassed the prompt); Cmd+M minimises, Cmd+H and the About/Services
  items are not available for now (see docs/DISTRIBUTION.md).
- **Installed app icon.** The Windows installer registered its icon under a name without an
  extension, so the Start menu, taskbar and Programs and Features showed the generic icon. Fixed;
  the build now checks the icon in every package (Windows exe and MSI, macOS bundle, Linux
  desktop entry and AppImage), and [docs/DISTRIBUTION.md](../DISTRIBUTION.md) describes what
  each package carries.

### Stitching, measured against PE-DESIGN 11.50

Every item below was measured on files saved by a licensed PE-DESIGN 11.50 through its normal
interface; the files, their settings and SHA-256 are in `compat/reference/MANIFEST.json`.

- **Gradation fills** place their rows at equal steps of the cumulative line count, as PE-DESIGN
  does; the U-shaped travel test's overlap with PE-DESIGN's stitches went from 0.83 to 0.89.
- **Auto satin bends** use PE-DESIGN's needle lattice (whole spacings from the far end, the
  remainder at the start point), forward start travel, an odd number of needle points ending on
  the start point. Mean needle distance to PE-DESIGN's stitches on the 60° bend: 0.20 → 0.08 mm;
  on the 90° bend: 0.16 → 0.07 mm.
- **Satin gradation** sews the split sawtooth's crossings on every other lattice line, needle for
  needle with PE-DESIGN's file (37/37 stitches).
- **Satin at the minimum density** adds a crossing on every line as PE-DESIGN does; the 40 × 6 mm
  column at 0.1, 0.2, 0.3 and 0.5 lines/mm exports record for record.
- **Under sewing type 2 (cross)**: lines at the direction minus and plus 45°, in halves from the
  far corners, as PE-DESIGN sews it (satin 395 vs PE's 404 stitches, fill 2650 vs 2651).
- **Text Transform presets 13 and 14** (fan out, fan in) are available, fitted from PE-DESIGN's
  letter corners.
- **Fit Text to Outline** on curves samples the path by Bézier halving as PE-DESIGN does, and
  ellipses are four Bézier arcs; the fitted circle now matches PE-DESIGN point for point (mean
  needle distance on the default Fit test 0.27 → 0.20 mm).
- **Machine formats** DST, EXP, JEF, SEW, XXX, PCS, HUS and VIP are written as PE-DESIGN 11.50
  exports them (record layout, headers, colour records, end records); all eight compare equal
  to PE-DESIGN's exports of the same design. SEW coordinates are design-relative, as PE-DESIGN's.
- **Trims:** a move of up to 2.3 mm between parts of the same colour is sewn across; longer moves
  are trimmed, as PE-DESIGN does (PE-DESIGN sews a 2.24 mm move and trims a 2.33 mm one).
- **References:** the harness grew from 110 to 172 specs, 165 of them at the reference
  tier, with sweeps for gradation (Max/Min, patterns, direction, Blend), satin bends (30/45/75°
  with and without Half Stitch), Fit text (spacing, size, fill and satin) and the machine stream
  (colour-block merging, satin columns 16–30 mm, trim bound), plus 30 PES object-class fixtures
  for the editable-PES reader.
- **Comparison tool:** `tools/pescmp.py`'s overlap no longer depends on the sewing direction
  (it understated matches by up to 0.3); the numbers above use the corrected tool. Median overlap
  over the reference pairs is now 0.931 (median needle distance 0.151 mm).

## Before you sew

- **Do a test sew-out on scrap fabric** before using a design on anything that matters. No
  OpenStitch file has been sewn on a Brother machine as part of testing yet.
- **Known differences from PE-DESIGN 11:**
  - **Text:** PE-DESIGN sews every letter stroke by stroke (each stroke a column with rows across
    it, for Fill and Satin text alike); OpenStitch still sews a text as one region, so letters
    with slanted or round strokes sew differently (satin text 221 vs 285 stitches on a 20 mm H).
  - **Programmable fill** sews about half of PE-DESIGN's stitch count; the pattern geometry is
    not yet calibrated.
  - **Feathered edge:** PE-DESIGN has separate top and bottom row switches and feather patterns;
    OpenStitch has one width and start/end/both.
  - **Multi-part regions** (the U shape, letters with holes) sew their parts in OpenStitch's
    order, not PE-DESIGN's.
  - **Motif lines** are uncalibrated: PE-DESIGN's default motif is Brother's own artwork, so
    there is no reference to compare with.
  - **Editable objects:** OpenStitch does not yet write PE-DESIGN 11's editable objects, so a PES
    from OpenStitch opens in PE-DESIGN as a stitch pattern.
- **Keep your original PE-DESIGN files.** Save OpenStitch's output under a new name.
- **Blocked features:** these protocols are undocumented and will not be reverse-engineered:
  wireless transfer and Link; USB Link and network machine settings; Card Reading.
- **macOS:** double-clicking a file in Finder does not open it in OpenStitch yet, and files
  can't be dragged onto the window. Use File ▸ Open, or pass the file on the command line.
- **Updating:** the packages are not code-signed, so the updater checks each download against
  `SHA256SUMS` served by GitHub over HTTPS; the MSI update shows Windows' usual
  publisher-unknown prompt.

The remaining known differences from PE-DESIGN 11, and which are fixed, are listed in
[docs/COMPATIBILITY_AUDIT.md](../COMPATIBILITY_AUDIT.md).
