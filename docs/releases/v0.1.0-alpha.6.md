# OpenStitch 0.1.0 alpha 6

The sixth alpha of OpenStitch, an independent, cross-platform embroidery design application for
macOS, Windows and Linux, built to work with Brother machines and with designs made in
PE-DESIGN 11. OpenStitch is not affiliated with Brother Industries.

Alpha 6 is the first version whose PES files PE-DESIGN 11 opens with **editable** objects:
shapes, text, Text Transform text and text fitted to an outline arrive in PE-DESIGN as objects you
can select, retype and re-sew, not as a stitch pattern. It also carries the fourth round of
PE-DESIGN 11.50 calibration (colour matching, image wizards, programmable fill, Concentric Circle
and Spiral fills, under sewing modes, satin rules) and reads and writes more of PE-DESIGN's files.
**It is still an alpha for testing, not for production work.** Read "Before you sew" below.

  again. Alternatively, run `xattr -dr com.apple.quarantine /Applications/OpenStitch.app`.
- **Windows:** in the SmartScreen prompt, choose **More info → Run anyway**.

## What changed since alpha 5

### PES files PE-DESIGN can edit

- **File ▸ Export ▸ PES ▸ PE-DESIGN 11** (and `design.export` with `pesVersion` 11) writes
  PE-DESIGN 11's own `#PES0110` layout. Checked in PE-DESIGN 11.50 on the owner's machine:
  - **Shapes** (fill and satin regions; running, zigzag, triple, E and V lines) open as editable
    shapes with their sewing attributes.
  - **Text** in Lato opens as editable text and can be retyped; spaces are kept.
  - **Text Transform** text opens at its preset and level (same stitch count as PE-DESIGN's own
    file, within 0.4 mm).
  - **Text fitted to an outline** stays attached: moving or reshaping the outline re-fits the
    text, and the Fit Text settings show as written (stitch counts identical to PE-DESIGN's).
  - Designs that fit 100 × 100 mm open on PE-DESIGN's Hoop Size page, with the total stitch count
    in the status bar; threads carry Brother's catalogue numbers and names.
- Still written as stitches only: programmable fill, motif and the other region types, gallery
  shapes and appliqué, Manual Punch, holes, vertical text and other fonts. The default PES export
  stays version 6.

### Colours

- Thread matching uses equal-weight squared RGB distance over the 61 Brother chart colours, as
  PE-DESIGN does (it reproduces all twelve of PE-DESIGN's picks in the owner's swatch test); ties
  go to the later chart entry.
- All 61 Brother chart colours have their catalogue numbers and names (`BROTHER_EMBROIDERY`).
- OpenStitch's own thread-chart CSV format (export and import), and the built-in charts listed by
  `threads.builtinCharts`. PE-DESIGN keeps user charts in a binary format OpenStitch does not read.

### Stitching, measured against PE-DESIGN 11.50

- **Concentric Circle and Spiral** region fills, PE-DESIGN's two radial sew types (density, run
  pitch, start point), match PE-DESIGN's 14 reference files within 3 %.
- **Programmable fill** follows PE-DESIGN's tiling: needle points within 0.2 mm of PE-DESIGN's on
  the owner's own patterns, and patterns made in Programmable Stitch Creator (`.pas`, `.pmf`,
  `.plf`) can be imported.
- **Under sewing:** PE-DESIGN's Density Dense / Medium / Light and its column under sewing types.
- **Tatami:** PE-DESIGN's Frequency brick stays the default; an OpenStitch-only seeded random
  stagger is available.
- **Satin:** the stretched-lattice rule from PE-DESIGN's length sweep; no minimum-crossing
  threshold (31 of 36 sweep columns match line for line).
- **Image wizards** (Auto Punch, Cross Stitch, Photo Stitch) checked against PE-DESIGN's captures:
  Auto Punch picks satin or fill by stroke width and orders colours as PE-DESIGN does; Cross
  Stitch sews PE-DESIGN's six diagonals per cell; stitch counts within about 4 %.
- **Sew order:** PE-DESIGN's order stays the default; a shortest-jump (2-opt) order is available
  as an option.
- **Long moves** over 204.7 mm are split as PE-DESIGN splits them; oversized designs warn with the
  smallest hoop they fit instead of failing.
- **Curves** keep PE-DESIGN's Bézier halving; very long curves are no longer coarsened.

### Files

- PMV pattern reader; the CSD, SHV and DST readers now match PE-DESIGN's exports of the same
  design.
- The compatibility harness grew from 172 to 252 specs, all passing, 244 at the reference
  tier (checked against a PE-DESIGN 11.50 file).

## Before you sew

- **Do a test sew-out on scrap fabric** before using a design on anything that matters. No
  OpenStitch file has been sewn on a Brother machine as part of testing yet.
- **Known differences from PE-DESIGN 11:**
  - **Text:** PE-DESIGN sews every letter stroke by stroke; OpenStitch still sews a text as one
    region. Arched text sews 0.7 mm wider than PE-DESIGN's on the 79 mm test arch.
  - **Feathered edge, multi-part region order, motif lines:** as in alpha 5.
  - **Editable PES:** see the list of object kinds still written as stitches above.
- **Keep your original PE-DESIGN files.** Save OpenStitch's output under a new name.
- **Blocked features:** undocumented protocols are not reverse-engineered (wireless transfer and
  Link, USB Link and network machine settings, Card Reading). PE-DESIGN's bundled fonts, motifs
  and patterns are Brother's content and are not read.
- **macOS:** double-clicking a file in Finder does not open it in OpenStitch yet.

The remaining known differences from PE-DESIGN 11 are listed in
[docs/COMPATIBILITY_AUDIT.md](../COMPATIBILITY_AUDIT.md).
