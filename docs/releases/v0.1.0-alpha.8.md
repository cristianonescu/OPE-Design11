# OpenStitch 0.1.0 alpha 8

The eighth alpha of OpenStitch, an independent, cross-platform embroidery design application for
macOS, Windows and Linux, built to work with Brother machines and with designs made in
PE-DESIGN 11. OpenStitch is not affiliated with Brother Industries.

Alpha 8 makes more of OpenStitch's PE-DESIGN 11 exports open in PE-DESIGN as editable objects
(appliqué groups, hole sewing, programmable and decorative fills, more region and line types,
the hoop and machine type), sews satin text stroke by stroke as PE-DESIGN does, adds PE-DESIGN's
second fill Stitch Type, and adds an **OpenStitch mode** to Auto Punch, Photo Stitch 1 and Photo
Stitch 2 beside the unchanged PE-DESIGN default.
**It is still an alpha for testing, not for production work.** Read "Before you sew" below.

## The builds are not code-signed

- **macOS:** the first time, right-click `OpenStitch.app` and choose **Open**, then **Open**
  again. Alternatively, run `xattr -dr com.apple.quarantine /Applications/OpenStitch.app`.
- **Windows:** in the SmartScreen prompt, choose **More info → Run anyway**.

## What changed since alpha 7

### PES files PE-DESIGN can edit (File ▸ Export ▸ PES ▸ PE-DESIGN 11)

- **Appliqué opens in PE-DESIGN:** a group's record now carries the number PE-DESIGN expects
  (one past its last member's), so PE-DESIGN opens OpenStitch's appliqué export as one group of
  all five objects. Groups of any objects are written again.
- **Confirmed in PE-DESIGN:** PE-DESIGN opened and re-saved OpenStitch's stitch group, Manual
  Punch, Curve Block and appliqué exports; the re-saves are now reference files.
- **Hole sewing** (Modify Overlap ▸ Set hole sewing) is read and written.
- **Programmable fill** is written with its pattern in the header's pattern list, and **decorative
  fill** with its pattern in the object; the Round 3 region types (motif, cross, concentric and
  the others) have their codes.
- **Stem, candlewick and chain lines** are written with PE-DESIGN's codes; all 22 of the owner's
  line files read. Motif lines are still refused.
- **Hoop and machine type:** the Design Settings' hoop and machine type are written as PE-DESIGN
  writes them, for the single-needle and multi-needle hoops; a turned hoop turns the machine
  stitches as well.
- **Appliqué colours:** the Applique Wizard's stages use PE-DESIGN's appliqué colours (PEC 62,
  63, 64), the tack-down and covering sew as one block, and the lines sit at PE-DESIGN's
  distances from the outline.
- **Import:** `import.pes` turns PE-DESIGN 11's shapes, Manual Punch blocks and Convert to Blocks
  output into editable OpenStitch objects. 149 of the owner's PE-DESIGN files now read and write
  back unchanged (121 at alpha 7).

### Lettering

- **Satin text is sewn stroke by stroke,** block by block in PE-DESIGN's Convert to Blocks order,
  with short travel along the outline and trims where PE-DESIGN trims. Satin text output changes
  from alpha 7.

### Stitching, measured against PE-DESIGN 11.50

- **Fill Stitch Type 2** (sloped rows), PE-DESIGN's second Stitch Type button, with a Stitch type
  choice in the inspector's Fill panel.
- **Concentric Circle and Spiral:** tie-in and lock on every run, grazing cut circles sewn whole,
  the outside-in order and triangle spiral sides from new captures (triangle 854 stitches
  against PE-DESIGN's 842).
- **Imported stitch files** (`stitches.import`) are centred on the Design Page, as PE-DESIGN's
  Import Patterns does.

### Image digitizing: a better-than-PE "OpenStitch" mode ➕

PE-DESIGN mode stays the default and is unchanged. The new **Mode** choice in the image dialog
switches Auto Punch, Photo Stitch 1 and Photo Stitch 2 (in colour) to OpenStitch mode:

- **Auto Punch:** colours chosen by appearance (CIELAB k-means, CIEDE2000 thread matching) and
  small-region cleanup. On the nine test images: colour error (mean ΔE00) 9.1 → 8.6, 14 % fewer
  stitches, 48 % fewer trims, stray specks 220 → 10. Thin line art keeps its lines.
- **Photo Stitch 1:** a perceptual palette and dithering in CIELAB: colour error 10.0 → 8.2 on
  nine photos, with 13 % more trims.
- **Photo Stitch 2:** a perceptual Auto Select and a thread mix computed in linear light: colour
  error 19.8 → 16.2 on seven images.
- Each mode is judged against PE-DESIGN mode on the Higgsfield test images
  (`tools/image_eval.py`). For some photos PE-DESIGN mode still sews truer (Photo Stitch 2's
  portrait: 13.4 against 18.3), so try both. Cross Stitch was measured too and gained nothing,
  so it has no OpenStitch mode.

### Colours and files

- **Thread-chart CSV export** in the layout PE-DESIGN's Import Chart reads (Code, Brand,
  Description, R, G, B).
- PEC 62–64 carry PE-DESIGN's appliqué RGB, and the PES colour list after the PEC section is
  written as PE-DESIGN writes it.

### App and documentation

- Nine new Higgsfield icons (Auto Punch, Edit Text, Font Filter Settings and others) and three
  update-dialog illustrations.
- The compatibility harness grew from 386 to 443 specs, all passing, 432 checked against a
  PE-DESIGN 11.50 file.

## Before you sew

- **Do a test sew-out on scrap fabric** before using a design on anything that matters. No
  OpenStitch file has been sewn on a Brother machine as part of testing yet.
- **Known differences from PE-DESIGN 11:** see "Known issues" in the README and
  [docs/COMPATIBILITY_AUDIT.md](../COMPATIBILITY_AUDIT.md). The main ones:
  - Fill text is still sewn as one region per letter; only satin text is sewn stroke by stroke.
  - Fill Stitch Type 1 and 2 rows are half a row off PE-DESIGN's at 30° and 45° (the angled-row
    anchor).
  - Photo Stitch 2's Auto Select picks different threads than PE-DESIGN's (its rule is not
    known yet).
  - Motif lines are not written to PE-DESIGN 11 files yet, and a design with several groups
    is exported without its groups (the objects are all there).
  - The Applique Wizard sews more stitches than PE-DESIGN's (1715 against 1063 on the 20 mm
    square): some of its defaults are not PE-DESIGN's yet.
  - Oversize designs: OpenStitch writes the stitches and warns; PE-DESIGN saves no stitches.
- **Keep your original PE-DESIGN files.** Save OpenStitch's output under a new name.
- **Blocked features:** undocumented protocols are not reverse-engineered (wireless transfer and
  Link, USB Link and network machine settings, Card Reading). PE-DESIGN's bundled fonts, motifs
  and patterns are Brother's content and are not read.
- **macOS:** double-clicking a file in Finder does not open it in OpenStitch yet.
