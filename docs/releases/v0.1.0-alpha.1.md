# OpenStitch 0.1.0 alpha 1

The first alpha of OpenStitch. It is an independent, cross-platform embroidery design
application for macOS, Windows and Linux, built to work with Brother machines and with designs
made in PE-DESIGN 11. OpenStitch is not affiliated with Brother Industries.

**This is an alpha for testing, not for production work.** Read "Before you sew" below.

## Downloads

## The builds are not code-signed

- **macOS:** the first time, right-click `OpenStitch.app` and choose **Open**, then **Open**
  again. Alternatively, run `xattr -dr com.apple.quarantine /Applications/OpenStitch.app`.
- **Windows:** in the SmartScreen prompt, choose **More info → Run anyway**.

## What's in it

- **Layout & Editing**, laid out like PE-DESIGN 11:
  - Application menu, ribbon with contextual tabs and a Quick Access Toolbar;
  - Sewing Order pane, and Import / Color / Sewing Attributes / Text Attributes panes;
  - Stitch Simulator, and a status bar with view modes and zoom;
  - light and dark themes.
- **Drawing and editing:**
  - shapes, Bézier outlines and point editing;
  - arranged copies and shape operations;
  - snap to grid and draggable entry/exit points;
  - the Satin Skeleton tool;
  - on-canvas character edits.
- **Stitches:** fill, satin and running, plus many line and region types. Satin sews a zigzag
  across the column, and fills travel inside the region (Running Stitch Path).
- **Lettering:**
  - bundled open-licence fonts and your own TrueType/OpenType fonts;
  - right-to-left and complex scripts, kerning and vertical text;
  - text on a path, monograms, Name Drop and templates;
  - Font Creator, including characters traced from an image.
- **Image to embroidery:** Auto Punch, Cross Stitch and Photo Stitch-style conversion.
- **Suite windows:** Design Database, Programmable Stitch Creator and Stitch Design Factory.
- **Files:**
  - read and write PES (v6 by default, with thread table and Design Property), PEC, DST, EXP,
    JEF, PCS, SEW, XXX, HUS and VIP;
  - read SHV, PHC and CSD;
  - editable `.osd` projects.
- **Output:** printing, including through the system print dialog, and transfer to USB media.
- **Automation:** `stitchtool`, an MCP server, and a loopback socket for driving the running
  editor (`--listen`).

## Before you sew

- **Nothing is verified against PE-DESIGN 11 or a real machine yet.**
  - No OpenStitch file has been opened in PE-DESIGN 11.
  - No OpenStitch file has been sewn on a Brother machine as part of testing.
  - The file formats are tested against independent open-source implementations (pyembroidery,
    libembroidery). Stitch generation is tested against OpenStitch's own expectations.
  - [docs/COMPATIBILITY_STATUS.md](../COMPATIBILITY_STATUS.md) shows the tier each test has
    reached.
- **Do a test sew-out on scrap fabric** before using a design on anything that matters.
- **Defaults are not calibrated.** Densities, stitch lengths, underlay spacing and pull
  compensation are OpenStitch's own defaults, not PE-DESIGN's.
- **PE-DESIGN won't see editable objects.** PES files written by OpenStitch are expected to
  open in PE-DESIGN as stitch patterns, with shapes and text not editable there. This has not
  been checked yet. Re-saving a PES made in PE-DESIGN keeps its stitches, threads and Design
  Property, but not its editable objects.
- **Keep your original PE-DESIGN files.** Save OpenStitch's output under a new name.
- **Blocked features:** these protocols are undocumented and will not be reverse-engineered:
  - wireless transfer and Link;
  - USB Link and network machine settings;
  - Card Reading.
- **macOS:** double-clicking a file in Finder does not open it in OpenStitch yet, and files
  can't be dragged onto the window. Use File ▸ Open, or pass the file on the command line.

The 20 highest-impact known differences from PE-DESIGN 11, and which are fixed, are listed in
[docs/COMPATIBILITY_AUDIT.md](../COMPATIBILITY_AUDIT.md).
