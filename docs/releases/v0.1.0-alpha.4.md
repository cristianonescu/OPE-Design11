# OpenStitch 0.1.0 alpha 4

The fourth alpha of OpenStitch, an independent, cross-platform embroidery design application for
macOS, Windows and Linux, built to work with Brother machines and with designs made in
PE-DESIGN 11. OpenStitch is not affiliated with Brother Industries.

Alpha 4 is the version that updates itself: from now on the editor finds the next release on its
own and installs it with one click. The stitching is the same as alpha 3's. **It is still an
alpha for testing, not for production work.** Read "Before you sew" below.

## Downloads

| System | File | Notes |
|---|---|---|
| macOS 11 or later (Apple Silicon and Intel) | `OpenStitch-v0.1.0-alpha.4-macos-universal.zip` | Unzip and move `OpenStitch.app` to Applications |
| Windows 10/11 (x86-64) | `OpenStitch-v0.1.0-alpha.4-windows-x86_64.msi` | Installer; adds `.osd` and "Open with" for `.pes` |
| Windows, portable | `openstitch-*-windows-x86_64.zip` | Unzip and run `openstitch.exe` |
| Linux x86-64 | `OpenStitch-v0.1.0-alpha.4-linux-x86_64.AppImage` | `chmod +x`, then run it; `--install-integration` adds the menu entry and file types |
| Linux x86-64 | `OpenStitch-v0.1.0-alpha.4-linux-x86_64.tar.gz` | Editor with `install.sh`, desktop entry, MIME types and thumbnailer |
| Command line (all systems) | `openstitch-cli-*` | `stitchtool` (scripting) and `openstitch-mcp` (MCP server) |
| Checksums | `SHA256SUMS` | SHA-256 of every file above; the editor's updater checks downloads against it |

## The builds are not code-signed

- **macOS:** the first time, right-click `OpenStitch.app` and choose **Open**, then **Open**
  again. Alternatively, run `xattr -dr com.apple.quarantine /Applications/OpenStitch.app`.
- **Windows:** in the SmartScreen prompt, choose **More info → Run anyway**.

## What changed since alpha 3

### OpenStitch now updates itself

- **Install alpha 4 by hand once.** Alpha 3 and earlier cannot update themselves: download the
  package for your system above and install it as before. Alpha 4 is the first version that
  can, so every version after it arrives by itself.
- **At startup** the editor asks GitHub whether a newer release exists. If one does, a dialog
  shows its release notes with three choices: **Dismiss**; **Don't remind me about this
  version**, which keeps quiet about that version until a newer one appears; and **Update**,
  which downloads the package for your system, checks it against the release's `SHA256SUMS`,
  installs it and restarts OpenStitch with your file still open. The check runs in the
  background, never delays the start, and stays silent when you are offline.
- **Every package updates in place:** the Windows portable zip and the MSI (Windows Installer
  asks for permission), the macOS app, and the Linux AppImage and tarball. A Flatpak updates
  through Flatpak.
- **Options** has *Check for updates at startup* (on by default), *Include pre-releases* and
  *Check for Updates Now*; Help has *Check for Updates*. About shows the release tag.
- **Unsaved work is safe:** Update waits until the design is saved.
- How it works, platform by platform, and what was verified:
  [docs/DISTRIBUTION.md](../DISTRIBUTION.md#updates) and
  [docs/research/updater.md](../research/updater.md).

### Releases

- Every release now ships `SHA256SUMS`, the SHA-256 of each package, for the updater and for
  anyone who wants to check a download by hand.

## Before you sew

- **Do a test sew-out on scrap fabric** before using a design on anything that matters. No
  OpenStitch file has been sewn on a Brother machine as part of testing yet; the first four
  sew-out files are prepared and waiting for the owner's machine.
- **Known differences from PE-DESIGN 11:**
  - **Text:** a satin text sews fewer stitches than PE-DESIGN's (221 vs 285 on a 20 mm H); text
    fills sew about 14 % more after the fill row change. Text Transform fan presets 13 and 14 are
    not available.
  - **Programmable fill** sews about half of PE-DESIGN's stitch count (2221 vs 4076 on the 40 mm
    test square); the pattern geometry is not yet calibrated.
  - **Feathered edge:** PE-DESIGN has separate top and bottom row switches and feather patterns;
    OpenStitch has one width and start/end/both.
  - **Multi-part regions** (the U shape, letters with holes) sew their parts in OpenStitch's order,
    not PE-DESIGN's.
  - **Motif lines** are uncalibrated: PE-DESIGN's default motif is its own artwork, so there is no
    reference to compare with.
  - **Machine formats other than PES** (DST, EXP, JEF, PCS, SEW, XXX, HUS, VIP): PE-DESIGN's
    exports exist as references but have not been compared yet.
  - **Editable objects:** OpenStitch does not yet write PE-DESIGN 11's editable objects, so a PES
    from OpenStitch opens in PE-DESIGN as a stitch pattern.
- **Keep your original PE-DESIGN files.** Save OpenStitch's output under a new name.
- **Blocked features:** these protocols are undocumented and will not be reverse-engineered:
  wireless transfer and Link; USB Link and network machine settings; Card Reading.
- **macOS:** double-clicking a file in Finder does not open it in OpenStitch yet, and files
  can't be dragged onto the window. Use File ▸ Open, or pass the file on the command line.
- **Updating:** the packages are not code-signed, so the updater checks each download against
  `SHA256SUMS` served by GitHub over HTTPS; the MSI update shows Windows' usual
  publisher-unknown prompt. An update the editor cannot apply (an app installed by an
  administrator, a read-only folder) says so and links to this page.

The remaining known differences from PE-DESIGN 11, and which are fixed, are listed in
[docs/COMPATIBILITY_AUDIT.md](../COMPATIBILITY_AUDIT.md).

## Feedback

Please open an issue for anything that sews differently from what you expect, crashes, or works
differently from PE-DESIGN 11. Attach the `.osd` or exported file and say which machine you
used.
