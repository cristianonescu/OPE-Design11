# OpenStitch 0.1.0 alpha 2

The second alpha of OpenStitch, an independent, cross-platform embroidery design application for
macOS, Windows and Linux, built to work with Brother machines and with designs made in
PE-DESIGN 11. OpenStitch is not affiliated with Brother Industries.

This is the first release checked against PE-DESIGN 11 itself. Simple test designs were made in a
licensed PE-DESIGN 11.50 and used only through its normal interface. OpenStitch's stitching and
files were then changed until they match. **It is still an alpha for testing, not for production
work.** Read "Before you sew" below.

## The builds are not code-signed

- **macOS:** the first time, right-click `OpenStitch.app` and choose **Open**, then **Open**
  again. Alternatively, run `xattr -dr com.apple.quarantine /Applications/OpenStitch.app`.
- **Windows:** in the SmartScreen prompt, choose **More info → Run anyway**.

## What changed since alpha 1

### Checked against PE-DESIGN 11.50

- 15 compatibility tests now compare OpenStitch with files saved by PE-DESIGN 11.50, and all
  pass. [docs/COMPATIBILITY_STATUS.md](../COMPATIBILITY_STATUS.md) lists them.
- OpenStitch's PES files open in PE-DESIGN 11 with their stitches, colours and Design Property.
  They open as stitch patterns: shapes and text are not editable there.

### Stitching now follows PE-DESIGN's defaults

These change how new designs sew. Existing `.osd` projects sew differently after you reopen them.

- **Under sewing is on by default** for fill, programmable fill and satin, as in PE-DESIGN.
  Fill under sewing runs along the edge 1 mm inside the outline, then rows across, and leads into
  the top stitching without a jump.
- **Density is 4.5 lines/mm** for fill and satin by default (it was 2.5 and 3.0).
- **Fill rows** run edge to edge, and Frequency shifts each row by its share of the stitch
  length, as in PE-DESIGN.
- **Satin** sews PE-DESIGN's sawtooth, with a tie-in at the start and a lock at the end. Auto
  direction spacing matches PE-DESIGN, and long crossings stay whole instead of being split at
  12 mm.
- **Optimize Sewing Order** keeps the drawing order within a colour, as PE-DESIGN does. It only
  groups by colour and links the facing entry and exit points. It no longer reorders same-colour
  objects by distance.

### Direction angles turn the PE-DESIGN way

- Every sewing direction you type (fill, programmable fill, satin, line slants) now turns
  **counter-clockwise** on screen, as in PE-DESIGN. A 45° fill in OpenStitch now looks like a 45°
  fill in PE-DESIGN.
- Projects saved by alpha 1 are converted when opened, so they keep their look. The next save
  writes the new project format, which alpha 1 cannot read.

### Files

- PES files save the Design Property in Windows-1252 with Windows line breaks, as PE-DESIGN does.
  Names such as "Ana Pérez" and comments of several lines now show correctly in PE-DESIGN.
- PES files no longer start each colour block with an empty stitch, and PE-DESIGN no longer
  loses a needle point at the start of each block.
- OpenStitch reads the Design Property of PES files saved by PE-DESIGN 11 (version `#PES0110`).

### Editor

- **New look:** an OpenStitch logo in the window, the taskbar, the Application button and About,
  and a short splash at startup (skip it with a click or a key; turn it off with `--no-splash` or
  in Options). New command icons, which follow the light and dark themes; the previous icons
  drawn in code remain as a fallback.
- **Illustrations:** illustrated empty states (empty canvas, Design Database, Programmable Stitch
  Creator, Name Drop), thumbnail placeholders, header art in the pattern wizards and in Image to
  Embroidery, and woven cloth under the stitches in the Realistic view.
- **Windows:** the editor now renders with DirectX 12, falling back to OpenGL. On some Windows
  machines, the Vulkan driver crashed OpenStitch at every start. Set `WGPU_BACKEND=vulkan` to use
  Vulkan anyway.
- The project moved to <https://github.com/cristianonescu/OpenStitch>. The old address redirects.

## Before you sew

- **Do a test sew-out on scrap fabric** before using a design on anything that matters. No
  OpenStitch file has been sewn on a Brother machine as part of testing yet.
- **Wide satin sews long stitches:** like PE-DESIGN, OpenStitch now sews each satin crossing as
  one stitch, however wide. Satin wider than about 10 mm can snag; use Fill for wide areas. (DST
  and other formats with a per-stitch limit still split stitches at that limit.)
- **Known differences from PE-DESIGN 11:**
  - **Gradation:** PE-DESIGN's gradation is a pattern with a maximum and a minimum density (by
    default 53 % to 5 %). OpenStitch has a single percentage, so gradation fills differ.
  - **Rectangle start point:** a rectangle drawn in PE-DESIGN starts and ends its sewing in the
    middle of its bottom edge. OpenStitch does not do this by default yet.
  - **Line stitches** (running, zigzag, E, V, motif) and text spacing are not calibrated against
    PE-DESIGN yet.
  - **Editable objects:** PES files from OpenStitch open in PE-DESIGN as stitch patterns. Re-saving
    a PES made in PE-DESIGN keeps its stitches, threads and Design Property, but not its editable
    shapes or text.
  - **Version 1 and truncated PES files:** files saved as truncated PES (`1t`, `6t`) open blank
    in PE-DESIGN, because they hold machine data only. Use the default version 6.
- **Keep your original PE-DESIGN files.** Save OpenStitch's output under a new name.
- **Blocked features:** these protocols are undocumented and will not be reverse-engineered:
  - wireless transfer and Link;
  - USB Link and network machine settings;
  - Card Reading.
- **macOS:** double-clicking a file in Finder does not open it in OpenStitch yet, and files
  can't be dragged onto the window. Use File ▸ Open, or pass the file on the command line.

The highest-impact known differences from PE-DESIGN 11, and which are fixed, are listed in
[docs/COMPATIBILITY_AUDIT.md](../COMPATIBILITY_AUDIT.md).
