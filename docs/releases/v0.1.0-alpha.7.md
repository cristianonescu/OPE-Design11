# OpenStitch 0.1.0 alpha 7

The seventh alpha of OpenStitch, an independent, cross-platform embroidery design application for
macOS, Windows and Linux, built to work with Brother machines and with designs made in
PE-DESIGN 11. OpenStitch is not affiliated with Brother Industries.

Alpha 7 widens what PE-DESIGN 11 can open as editable objects (Manual Punch blocks, appliqué,
stitch groups, text converted to blocks), brings Text Transform, the satin bend and the eight
machine-format writers in line with PE-DESIGN 11.50, adds a Photo Stitch 2 generator and a contour
fill, and has a new README with what works, what is missing and what is known not to match yet.
**It is still an alpha for testing, not for production work.** Read "Before you sew" below.

- **macOS:** the first time, right-click `OpenStitch.app` and choose **Open**, then **Open**

- **Windows:** in the SmartScreen prompt, choose **More info → Run anyway**.

## What changed since alpha 6

### PES files PE-DESIGN can edit (File ▸ Export ▸ PES ▸ PE-DESIGN 11)

- **Manual Punch blocks:** Straight Blocks and Curve Blocks are written as PE-DESIGN's own
  blocks (curve handles within 0.1 mm of PE-DESIGN's on the owner's samples).
- **Appliqué:** the Applique Wizard's material, tack-down, covering and cutting lines are written
  with PE-DESIGN's appliqué colours.
- **Stitch patterns** are written as PE-DESIGN stitch groups instead of being refused.
- **Text converted to blocks** (PE-DESIGN's Text ▸ Convert to Blocks) is read and written.
- Thread tables use the codes of all 61 BROTHER EMBROIDERY colours and PE-DESIGN's 29 "Ver4
  Option Color" threads.
- E and V lines carry their stitch width in PE-DESIGN's own field, so their size matches.
- Reading: OpenStitch reads PE-DESIGN's stitch groups, Manual Punch blocks, appliqué and
  converted text; 121 of the owner's PE-DESIGN files read and write back unchanged.
- **Not yet confirmed in PE-DESIGN:** stitch groups, Manual Punch and Curve Blocks and appliqué
  are written in PE-DESIGN's layout, byte for byte where the owner's files allow, but PE-DESIGN
  has not opened OpenStitch's export of them yet (their four references are pending). A Curve
  Block's handles are within 0.1 mm of PE-DESIGN's, not identical.

### Lettering

- **Text Transform levels:** `text.add` takes PE-DESIGN's level, and the envelope warps the
  capital-height box as PE-DESIGN does: 105 of the owner's 108 level captures and 51 of 52
  defaults within 0.5 mm.
- The arched Text Transform now sews the same stitches on Windows, macOS and Linux.
- First steps of stroke-by-stroke lettering (letters cut into strokes as PE-DESIGN cuts them);
  sewing still uses the whole-letter method in this release.

### Stitching, measured against PE-DESIGN 11.50

- **Satin bends past 100°** sew a fan as PE-DESIGN does (120° test: 171 stitches against
  PE-DESIGN's 161, was 273).
- **Motif fill and motif line** travel and tie in as PE-DESIGN (130 and 23 needle points, as
  PE-DESIGN).
- **Decorative fill** from your own free-line `.plf` patterns, centred on the shape as PE-DESIGN
  centres it (PE-DESIGN sews more passes over the line: 292 stitches against 73 on the test).
- **Spirals** wind and close as PE-DESIGN's do, with the start point on a corner or an edge.
- **New fills start at 45°**, as PE-DESIGN's shape tools do (existing designs keep their angle).
- **Contour fill** (not in PE-DESIGN): rings, single or double spiral and echo lines.

### Image digitizing

- **Photo Stitch 2** generator: PE-DESIGN's line screen with one fixed angle per thread, the four
  named Color Sets and Mono (named sets within 2–7 % of PE-DESIGN's stitch counts).
- **Photo Stitch 1** joins runs within a colour: far fewer trims (426 → 99 on the mono test).
- **Auto Punch** picks satin or fill and the fill direction as PE-DESIGN does at every image
  resolution, and orders colours as PE-DESIGN. Its automatic colour count now ignores the blended
  shades along anti-aliased edges, so flat graphics keep their colours (PE-DESIGN's automatic
  count on the test images).
- A library of Higgsfield-generated test images and a "From image to embroidery" gallery in the
  README.

### Colours and files

- SVG import snaps colours to the nearest Brother thread, as PE-DESIGN's vector import does.
- The eight machine-format writers (DST, EXP, PCS, HUS, VIP, JEF, SEW, XXX) match PE-DESIGN's
  exports of its own design stitch for stitch.
- Version 6 PES files carry a custom page size and a rotated hoop as PE-DESIGN reads them.
- PE-DESIGN's oversize saves (an empty machine section) are reported instead of misread.
- The PEC colour list now gives each colour block its nearest Brother entry, as PE-DESIGN writes
  it; two colours can share an entry, so some PEC colour bytes differ from alpha 6's output.
- PEC 42 (307 LINEN) has PE-DESIGN's RGB; a 94-entry sew palette is listed in
  `threads.builtinCharts` (its matcher is not verified against PE-DESIGN and no default uses it).

### App and documentation

- New Higgsfield icons for many commands and illustrations for empty panes.
- The README now lists every feature, what is not implemented yet, the known issues and what is
  planned, with current screenshots.
- The compatibility harness grew from SPECS6 to SPECS specs, all passing, REFTIER checked against
  a PE-DESIGN 11.50 file.

## Before you sew

- **Do a test sew-out on scrap fabric** before using a design on anything that matters. No
  OpenStitch file has been sewn on a Brother machine as part of testing yet.
- **Known differences from PE-DESIGN 11:** see "Known issues" in the README and
  [docs/COMPATIBILITY_AUDIT.md](../COMPATIBILITY_AUDIT.md). The main ones:
  - Text is still sewn as one region per letter, not stroke by stroke.
  - Fill Stitch Type 2 (PE-DESIGN's sloped rows) is not implemented yet.
  - Auto Punch picks a different Brother thread than PE-DESIGN for some colours (13 of 20 test
    colours match).
  - Oversize designs: OpenStitch writes the stitches and warns; PE-DESIGN saves no stitches.
- **Keep your original PE-DESIGN files.** Save OpenStitch's output under a new name.
- **Blocked features:** undocumented protocols are not reverse-engineered (wireless transfer and
  Link, USB Link and network machine settings, Card Reading). PE-DESIGN's bundled fonts, motifs
  and patterns are Brother's content and are not read.
- **macOS:** double-clicking a file in Finder does not open it in OpenStitch yet.
