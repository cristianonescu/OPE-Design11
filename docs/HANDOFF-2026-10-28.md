   loss. 3. **Same on the machine** (PEC stream equivalence, then sew-out records).

   ([research/competitive-features.md](research/competitive-features.md)).

no program files, no activation data); every behaviour-changing PR updates FEATURE_MATRIX,

Higgsfield (variants may be derived from the Higgsfield original); a release needs the full gate
(below); stacked PRs are retargeted to `main` before their base merges (GitHub auto-closes a PR
whose base branch is deleted).

## Tracks and where to pick each one up

- **Stroke-wise text** (new, highest value): PE-DESIGN splits every letter into strokes and sews
  each as a column with rows across it, for Fill and Satin text alike; OpenStitch sews a text as
  one region. This is the structural gap behind every text-* spec below 0.85 overlap. References
  exist (text-fit-*, text-transform-*, text-sewing-order, round-3 AHHHH files).
- **Satin:** satin-auto-bend-120 (PE 161 vs our 267 stitches), the lattice phase on long start
  legs (reference request: a 60° band with start legs 20/25/35 mm), Half Stitch for Auto satin.
- **Fill:** u-gradation-nous (PE 434 vs our 366 stitches: the row needle grid, not the row
  positions), PE's section order for fills in several parts, programmable fill density.
- **Machine stream:** colour-block merging in first-occurrence order (recorded, not yet
  implemented), satin columns 16–30 mm sent whole (209 vs 208 stitches), hoop sizes, PEC
  thumbnail; then a first sew-out on the owner's machine.
- **PES editable objects:** the reader parses the `#PES0110` classes (fixtures for 30 object
  kinds landed today); next is turning them into editable OpenStitch objects, then writing them.
- **Parked references with numbers:** text-fit-base-unfitted (text.add anchor), merge bound of
  same-colour blocks (record the 40 × 6 column at 1, 1.5, 2 lines/mm).
- **Beyond PE-DESIGN:** start from
  [research/beyond/readiness.md](research/beyond/readiness.md): B6 density profiles, B1 contour
  fill, B8 crosshatch, B7 puff, B12 carving, B10 variable-width satin, with B5 (compensation
  model) early because later items read it. All land in `openstitch-design`/engine. A daily
  competitor scan (scheduled task on the owner's machine) appends to competitive-features.md
  only when something material appears.
- **PE-DESIGN access:** a new reference session must request computer-use access to PE-DESIGN
  11 again (granted per session; the owner approves the dialog).

## How the day was run (keep this)

Coordinator loop with parallel track sessions, each owning disjoint files and ending in PRs; a
merge queue script merges a PR only when its three OS jobs pass and GitHub reports it mergeable,
waiting while mergeability is still being computed; shared compat files (MANIFEST.json,
COMPATIBILITY_STATUS.md, the audit, matrix and roadmap) conflict on every merge, so chains of
PRs rebase one at a time on the coordinator's ping, and when CI is slow (30–50 min per job
today) a track's remaining PRs are combined into one.
